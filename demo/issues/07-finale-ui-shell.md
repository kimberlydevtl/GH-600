# Finale 1: upgrade the UI to the app shell and design rules

**Track:** Finale (after class rehearsals, not live in class)

## Goal
The web app uses shadcn/ui, an app shell (sidebar, top bar, user menu, light and dark
theme) and follows the design rules in the `ui-shell` skill.

## Success criteria
- Same features and behaviour as today, including Trainer mode and the user switcher.
- Status chips use one shared component (soft tint plus dot, no outline).
- No outlined buttons, no accent bars, one accent colour.
- Ladder rungs 1 to 6 pass. Light and dark themes both readable.

## Scope
In: `web/` only. Out: `api/`, `mcp/`.

## Risk
Low. Use the `ui-shell` skill.
